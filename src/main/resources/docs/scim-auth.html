Authentication Model

This SCIM service uses a static shared secret Bearer token. There is no OAuth 2.0 flow. The token is generated by the SCIM service administrator and must be configured manually in the SCIM client.

Header Format

Authorization: Bearer <your-static-token>

Token Rules

  • Token must be sent on every request
  • Token is case-sensitive
  • Token must be kept secret
  • Rotate token if compromised
