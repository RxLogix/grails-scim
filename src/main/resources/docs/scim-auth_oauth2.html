SCIM Authentication

This SCIM service uses OAuth 2.0 Bearer Token authentication.

Header Format

Authorization: Bearer <access_token>

Required Scope

scim.provisioning

Example Request

curl -X GET {{BASE_URL}}/scim/Users \
  -H "Authorization: Bearer eyJhbGciOi..." \
  -H "Content-Type: application/scim+json"

Token Flow

Use OAuth 2.0 Client Credentials Flow to obtain access tokens.

Errors

  • 401 - Missing or invalid token
  • 403 - Insufficient scope
